Welcome

Scribe is a local tabbed viewer for pages the Cursor agent presents. Keep this window open. New pages show up as tabs.

Search

  • Ctrl+D opens a palette over Scribe. Type to search titles, page content, and saved form data across every page in the Library. A prefix switches the search: = looks through agent threads (change prefixes in Settings). Enter on a thread opens it in the chat.
  • With an empty query it lists open tabs, then recently closed pages. ↑ ↓ move, Enter opens the page (as a tab if it was closed), Esc closes.

Tabs

  • Closing a tab (× or middle-click) keeps the page in the Library. Pinned tabs ignore middle-click; use ×. Shift+click × (or Shift+middle-click) deletes the page; the notice that appears has Undo, and Ctrl+Z works too. Deleted pages go to the Trash (Library ⋯ menu → Trash) for 7 days, where you can restore them or delete them for good.
  • This Welcome page is part of the app. Closing it dismisses it; Ctrl+H opens it again.
  • Right-click a tab to pin or unpin it. Pinned tabs stay on the left. Clear closes unpinned tabs and leaves pinned tabs alone. Settings (logo) → Tabs can hide the Clear button.
  • Hover a tab for its full title, key, created and updated times, and Library folder.
  • Double-click a tab (or right-click → Copy key) to copy a reference like Scribe tab sprint-notes. Paste it into a chat so the agent knows exactly which page you mean, or into a Todo or Kanban card to link the page.
  • Drag a tab to move it inside the pinned or unpinned group. Drop does not switch the page. Escape cancels.
  • Right-click a tab or a Library row to export that page with its data and images.
  • Right-click inside a page for Ask agent, Copy, Copy link address, Select all, and Copy page key. Text fields keep the browser's menu, and Shift+right-click always shows it. With text selected, Ctrl+K or Ctrl+L also opens the chat with the selection attached.
  • A dot on a tab means it was updated while you were looking at another tab.
  • If tabs overflow, scroll the strip with the mouse wheel. Settings (logo) has a toggle for smooth scrolling.

Links, peeks, and splits

  • Pages can link to other pages and to websites. A link opens its target as a tab, as a peek (a card over the page area, for a quick look without opening a tab), or in a split beside the current tab.
  • Hold Ctrl to navigate, Shift to split, or Alt to peek. This works on links in pages, on Library rows (click or Enter), and in search.
  • Without a modifier, a link does what its page asked for. Otherwise, a link to a Scribe page follows Settings → Links (Navigate at first), and a website opens in your browser. Ctrl+click on a website always goes to the browser.
  • A peek closes with Esc, a click outside it, or ×. Its header can open the page as a tab or move it into a split, without reloading it. A link to another page inside a peek stacks, and ← goes back.
  • A split shows two to four pages as panes in a row, each with its own header, and all of them are tabs in the strip. The strip and the floating chat follow the pane you last clicked or typed in: picking another tab changes that pane, and picking another pane's tab moves focus to it. A link opened in a split shows in the pane after the one you are in, replacing what was there. Splitting the tab you are on opens a New page beside it. Close a pane with its ×; the page stays a tab.
  • To add a pane, drag a tab onto the page area and drop it beside a pane; dropped on the middle of a pane, it replaces that pane's page. A pane's header drags the same way to move it. A pane is added while each keeps about 360px of width, and a tab replaces the pane under it after that. Drag a border between panes to resize the two beside it; double-click a border to make all panes even. Hover a border for buttons that swap its two panes or stack the panes top and bottom. In narrow windows a split opens as a peek instead.
  • Some websites don't allow being shown inside other pages. Their peek or split says so and offers to open them in your browser. A site that relies on its login may look logged out inside Scribe.
  • When you close a tab you reached through a link, Scribe returns you to the page the link was on.

Library and templates

  • The Library button to the right of Clear, or Ctrl+B, opens the sidebar. It has two tabs: Library and Templates. A badge on that button means closed pages were updated, not the total count.
  • The Library holds every page, open or closed. Open pages have an accent bar and a brighter title; the current tab's row is filled. Pinned pages have a faint warm tint.
  • Click a page to open it or switch to it; middle-click opens it in the background. Click a folder to expand or collapse it; right-click it to open or close all its pages, rename, move, export, or delete it.
  • Drag rows to reorder them or move them into folders (hover a collapsed folder to expand it). Drag a Library page onto the tab strip to open it at that spot, or drag a tab into the Library to file it and close the tab. While dragging a tab, hover the Library button to open the sidebar.
  • Double-click or F2 renames a page or folder. Agents keep their hands off a title you set for 24 hours. Alt+↑ ↓ nudges the focused row, Delete deletes it.
  • Deleting a folder offers to move its contents up or delete everything. A folder delete, or any bulk delete, is one undo step.
  • Templates are reusable pages the agent creates when you ask. Click one to fill its form and Open a pinned copy. While that copy is selected, Edit on the right of the tab strip changes that page’s values.
  • Improving a template updates every page created from it. If the new version cannot use the old page data, the page is blocked until the agent fixes the data.
  • Drag the inner edge of the sidebar to resize it. Settings → Layout chooses whether the Library and agent panes sit on the left or the right. Esc clears the search box first, then closes the sidebar.

Import and export

  • Ctrl+S still saves the current page as a plain HTML file. Interactive data and attached images are not included, so that file is a snapshot of the markup, not a working Scribe page.
  • Settings (logo) has Import, Export, and Export all. Export is a .scribe.json pack: HTML, title, pin, open or closed, Library folder and position, JSON state, and images. A page made from a template also carries that template and its form values. Export all is the same format with every user page and every template; right-click a folder to export just that folder. The Welcome page is skipped.
  • Import accepts a saved HTML file, a single-page export, or an export-all file. It detects the type from the contents. Existing pages are not overwritten; a colliding key gets a suffix. Imported template pages stay linked to their template. If Scribe already has an identical template, it is reused; a template with the same name but different content is added as a separate template.
  • Drop a file on the settings overlay (anywhere while Settings is open), on the tab strip, or on the Library sidebar. Settings and the tab strip keep the open or closed status from the file (default open). The Library sidebar imports everything closed.

Persistence

The Library, its folders, open tabs, each page's state, and the last 10 deletes are saved to %LOCALAPPDATA%\scribe\scribe.sqlite, so they survive Cursor and Scribe restarts. The Library is not capped; pages stay until you delete them. Override the folder with the SCRIBE_HOME environment variable if needed.
